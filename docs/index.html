Conector Aruba AirWave — Guía de configuración

Última actualización: octubre 2026

¿Qué es y para qué sirve?

El conector Aruba AirWave permite que el agente de Ruvic monitoree la infraestructura Aruba gestionada por AirWave: dispositivos y su estado, métricas generales y clientes conectados. Es de solo lectura. Puedes pedirle cosas como:

  • "¿Qué access points están caídos ahora mismo?"
  • "¿Cuántos clientes tiene conectados el AP del piso 2?"
  • "¿A qué AP y SSID está conectado el equipo 12:34:56:78:90:AB?"

Operaciones soportadas:

OperaciónQué hace
devices.listDispositivos con estado, IP, carpeta y clientes
device.statusDetalle de un dispositivo y sus radios
metrics.getEstadísticas generales de AirWave
clients.getDetalle de un cliente conectado por MAC
Solo lectura El conector no cambia nada en AirWave. Usa un usuario con rol Monitor Only.

Prerrequisitos

  • AirWave Management Platform 8.x con acceso HTTPS.
  • Acceso de administrador para crear un rol y un usuario de solo lectura.
  • Conectividad HTTPS desde la plataforma Ruvic hasta AirWave.

Configuración en el fabricante

Vas a crear un rol de solo lectura y un usuario dedicado.

  1. Crea el rol de solo lectura.

    En AMP Setup → Roles → Add, crea "Ruvic Monitor" de tipo Monitor Only y limita las carpetas.

  2. Crea el usuario dedicado.

    En AMP Setup → Users → Add, crea "ruvic-api" con el rol anterior.

    [ Captura: creación del usuario en AMP Setup → Users — reemplazar por assets/img/airwave-user.png ]

Permisos requeridos

Un rol Monitor Only es suficiente: el conector solo lee.

PermisoPara qué lo usa el conector
Monitor OnlyLeer dispositivos, métricas y clientes
Carpetas (Top/…)Limitar qué dispositivos puede ver el agente

Configuración en Ruvic

Entra a Settings → Conectores, busca la tarjeta Aruba AirWave y pulsa Configurar. Diligencia el formulario con los valores de la sección anterior:

Campo del formularioValor
URL de AirWaveURL de AirWave, ej. https://airwave.miempresa.com
UsuarioUsuario dedicado de solo lectura
ContraseñaContraseña del usuario. Se guarda cifrada
Verificar certificado SSLDesactívalo solo con certificados autofirmados en redes de confianza
Timeout de conexión (segundos)Opcional; 30 segundos por defecto

Guarda y pulsa Probar conexión: la plataforma valida las credenciales y el acceso.

[ Captura: formulario del conector Aruba AirWave en Settings → Conectores — reemplazar por assets/img/aruba_airwave-form.png ]

Verificación

  1. Test de conexión exitoso.

    El botón Probar conexión debe responder con éxito y la tarjeta debe quedar en estado Configurado.

  2. Prueba mínima con el agente.

    Abre una conversación nueva y pídele:

    "¿Cuántos dispositivos hay en AirWave y cuántos están caídos?"

    El agente debe responder con los conteos reales.

Solución de problemas

Mensaje / síntomaCausa probable y solución
"Usuario o contraseña de AirWave inválidos"AirWave devolvió la página de login: revisa credenciales y que el rol permita usar la API.
"No existe el dispositivo con ID …"Usa el ID numérico de list_devices, no el nombre.
"AirWave no tiene registro del cliente …"La MAC es incorrecta o el cliente no se ha conectado recientemente.
La consulta tarda muchoLa lista de dispositivos es grande. Aumenta el timeout o filtra por estado.

Preguntas frecuentes y notas de seguridad

¿El agente puede reiniciar un access point?

No. El conector es de solo lectura.

¿Puedo limitar qué equipos ve el agente?

Sí, restringiendo las carpetas del rol del usuario.

¿Qué hago si la contraseña se filtra?

Cámbiala en AMP Setup → Users y actualízala en el formulario.
